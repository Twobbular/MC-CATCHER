MC-CATCHER

Linux Installation Guide

MC-CATCHER is a Minecraft Java Edition server monitoring tool. It can monitor a server, detect publicly available player names, record player counts, detect joins and leaves, and save everything to a CSV log.

1. Download MC-CATCHER

Download the MC-CATCHER Python script (.py) from the official MC-CATCHER website:

MC-CATCHER Home-Page

You only need the .py file. You do not need to download the entire website.

2. Put the Script Somewhere

Move the downloaded .py file somewhere convenient, such as your Home folder or a folder specifically for MC-CATCHER.

For example:

/home/yourusername/MC-CATCHER/minecraft_watcher.py

3. Open the Script

Open the .py file using a text editor such as Text Editor, Gedit, or another plain-text code editor.

Find these settings near the top of the script: 

SERVER = ""
LOG_FILE = "/i/forget/what/it/says/and/im/too/lazy/to/copy.csv"

4. Enter Your Minecraft Server

Change the value of SERVER to the address of the Minecraft Java Edition server you want to monitor.

For example:

SERVER = "play.example.com"

Do not include https://.

5. Choose Where the CSV Is Saved

Change LOG_FILE to the location where you want MC-CATCHER to save its CSV log.

For example:

LOG_FILE = "/home/yourusername/Documents/minecraft_log.csv"

You can choose any location where you have permission to create files.

Tip: Make sure the folder already exists. MC-CATCHER can create the CSV file, but it will not automatically create missing folders.

6. Install Python

Open Terminal and run: 

sudo apt update
sudo apt install python3 python3-venv

7. Create a Virtual Environment

Open Terminal in the folder containing MC-CATCHER and run: 

python3 -m venv venv

Then activate it: 

source venv/bin/activate

Your Terminal should now show (venv) somewhere at the beginning of the command prompt.

8. Install MCStatus

MC-CATCHER uses the mcstatus Python package to query Minecraft Java Edition servers. 

pip install mcstatus

9. Run MC-CATCHER

Run the Python script: 

python minecraft_watcher.py

MC-CATCHER will now begin monitoring your server.

10. The Server Can Be Offline

MC-CATCHER does not need the Minecraft server to be online when you start it.

If the server is offline, MC-CATCHER will keep checking it: 

[12:30:00] 🔴 Server unavailable — still waiting...
[12:30:15] 🔴 Server unavailable — still waiting...
[12:30:30] 🔴 Server unavailable — still waiting...

When the server becomes available, MC-CATCHER will automatically detect it: 

[12:31:00] 🟢 SERVER ONLINE
[12:31:00] Initial player list: Steve
[12:31:00] Online (1): Steve

11. Viewing the CSV

Open the location you selected for LOG_FILE. MC-CATCHER will create a file ending in .csv.

You can open the CSV with applications such as:

  • LibreOffice Calc
  • Microsoft Excel
  • Google Sheets
  • Any other spreadsheet application

MC-CATCHER saves its log after every check, so the CSV is continuously updated while the program is running.

12. Stopping MC-CATCHER

To stop MC-CATCHER, press: 

Ctrl + C

If you activated the virtual environment, you can leave it with: 

deactivate

Troubleshooting

Python is not installed

sudo apt update
sudo apt install python3 python3-venv

mcstatus is missing

Make sure the virtual environment is activated: 

source venv/bin/activate

Then install mcstatus: 

pip install mcstatus

The server is offline

This is normal. MC-CATCHER will continue checking until the server becomes available.

The CSV is not being created

Check that the folder specified by LOG_FILE already exists and that your user account has permission to write there.

Important: MC-CATCHER uses publicly available Minecraft server status information. Player-name detection may not always provide a complete list of players. MC-CATCHER should not be treated as a replacement for server-side logs or administrator tools.
